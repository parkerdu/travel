26周六

D1｜天府机场 → 康定 → 新都桥隐沫度假酒店

14:00拿车后直达新都桥；红海子、格底拉姆安排在D5白天。

约410—440km纯驾驶约6.5—8h
11:00—12:30🍜 起床 + 午饭

在机场酒店完成洗漱、退房并吃午饭，作为当天第一餐。

13:20—14:00→ 神州租车验车

拍摄车身、轮胎、轮毂、底盘可见区域、油量、电量和里程，确认非铺装道路保险及救援范围。

14:00—14:15⛽ 天府机场附近加满油 / 补足电

以满油状态进入川西；保存加油小票与出发油表照片。

14:15→ 完成加油后驶向康定

走成雅/雅康高速；途中安排厕所和补能短停。

18:00—18:40🍜 康定快餐

17:30核对实时路况并向新都桥酒店报备到店时间，饭后走G318。

21:00—22:00◆ 新都桥隐沫度假酒店 · 约3,460m

22:00作为当晚驾驶上限；使用弥散供氧，快速洗漱后休息，并提前告知酒店预计晚到。

路况方案：雅康高速严重管制、结冰或驾驶员疲劳时改住康定，并在18:00前处理新都桥订单；同时重新核算D2措普沟入园时间。
27周日

D2｜新都桥 → 雅江 → 理塘 → 姊妹湖 → 措普沟 → 巴塘海友

措普沟硬性必到；这是除D3之外的第二个必要早起日。

约400—450km纯驾驶约8—9h
07:00—08:00🍜 起床 + 快速早餐/退房

前一晚整理好行李、路餐和D3反穿补给；早饭快速吃完或打包带走，08:00准时出发。

08:00—12:00● 天路十八弯 / 卡子拉山 / 毛垭草原

在正规观景位各停5—10分钟，沿G318连续向理塘推进。

12:00—12:35🍜 理塘快餐 ⛽ 理塘加满油

理塘完成午饭与燃油补给后继续西行；按理塘至巴塘之间无可靠加油点安排。

14:10—14:45● 海子山姊妹湖

在G318观景台停留约35分钟；14:45驶向措普沟游客中心。

15:30—18:00● 必到｜措普沟精华

前一天向景区确认预约、最后入园和末班景交时间；集中游览措普湖、温泉地貌等核心区域。

20:00—21:30◆ 海友酒店（甘孜巴塘店）· 约2,580m ⛽ 巴塘再次加满油

离开景区后沿铺装主路抵达巴塘。到店简单晚饭；完成油电补给，下载格聂南线离线地图，向下则通民宿确认次日道路和晚餐。

措普沟时间优先：进度落后时，将天路十八弯、卡子拉山和毛垭草原调整为沿途车览，理塘采用20分钟路餐；景区临时关闭或道路封闭时按官方通告执行。
28周一

D3｜巴塘 → 夯达营地 → 则巴村 → 格聂之眼 → 下则通村

格聂南线反穿核心日；三个指定打卡点全部列为必到。

约210—250km纯驾驶约9—11h
07:00—08:00🍜 起床 + 压缩早餐/退房

行李、离线地图和车辆补给在前一晚完成；7:30早餐开放后快速吃或打包，08:00出发。

08:00→ 准时反穿

地理顺序：巴塘 → 波密乡/格木村 → 扎瓦拉垭口 → 劳者龙巴 → 热梯河谷 → 夯达营地 → 则巴村 → 新冷古寺路口 → 格聂之眼 → 下则通村。提前下载离线地图，岔路结合民宿和现场指引确认。

09:00—13:00● 西段精华

扎瓦拉、格木村、劳者龙巴和热梯河谷每处控制10—20分钟；落石带、盲弯和涉水点保持连续通行。

13:00🍜 安全位置路餐

饮水和路餐在巴塘备齐，在视野开阔的停车位置用餐。

13:30—14:30● 必到 1｜夯达营地

在营地指定位置停车，拍摄格聂南坡和河谷；同时确认天气、车况和剩余日照时间。

14:40—15:40● 必到 2｜则巴村

村落和雪山机位停留约40—60分钟；车辆停在指定区域并保持村道通畅，15:40继续前往格聂之眼。

17:00—17:45● 必到 3｜格聂之眼

在正规停车位下车，沿现有步道接近并保护草甸。若17:30仍在途中，则调整为D4 09:30第一站。

顺路条件项○ 老冷古寺｜有余量则去

14:00前抵达新冷古寺、天气和身体状态良好、当地摩托或马匹可立即往返，并确认能在天黑前完成格聂之眼及入住时进入；时间不足则略过，D4按单向路线继续。

18:15—19:30◆ 格聂云庭富氧民宿 · 下则通村约3,800m

完成晚餐、供氧和停车，随后在下则通休息。

20:30—21:30★ 格聂银河 / 星空观察

步行前往民宿老板推荐的村内开阔安全点，面向西南观察；使用红光照明并适应黑暗约20分钟。根据云量和月光，在银河、星空与雪山月色之间选择拍摄主题。

默认住已订富氧民宿连续无信号多座4600—5000m垭口
夯达车宿备选：主方案入住下则通富氧民宿。天气稳定、身体状态良好、营地同意且低温睡袋与通风装备齐全时，可启用夯达车宿方案。
29周二

D4｜下则通 → 自然中心/小木屋 → 格聂镇 → 理塘 → 雅江松茸村

从下则通经格聂镇单向退出，晚上利用G318铺装主路推进。

约260—310km纯驾驶约7—9h
08:00—09:30🍜 起床 + 民宿早餐/退房

确认轮胎、底盘和油量，带好路餐，9:30按单向路线出发。

09:30—10:10● 格聂之眼补拍时段

D3已经完成则直接前往自然中心；D3行程延误时在这一时段补拍，随后向格聂镇方向前进。

10:15—11:30● 格聂自然中心 / 海蒂同款小木屋

两处合并控制在75分钟，拍完经格聂镇、伊拉卡、铁匠山方向退出。

11:30—12:00🍜 路餐

使用随车路餐，吃完继续经格聂镇、伊拉卡、铁匠山前往理塘。

15:30—16:10🍜 理塘下午餐 ⛽ 理塘加满油

完成返程段燃油与电量补给，16:10前沿G318东行去雅江松茸村。

19:30—21:30◆ 雅江阿美达民宿 · 松茸村约2,870—3,000m

地址为八角楼乡松茸村55号，靠近G318且可停车。提前联系预订松茸鸡汤；入夜后的行驶全部在G318铺装主路。

到店后🍜 松茸鸡汤晚餐

在民宿享用松茸鸡汤并体验藏式村落住宿。

D4单向路线：下则通 → 格聂自然中心/小木屋 → 格聂镇 → 伊拉卡 → 铁匠山 → 理塘。老冷古寺时间不足时在D3略过，D4按上述方向前进。
30周三

D5｜松茸村 → 新都桥 → 格底拉姆 → 红海子 → 康定 → 崇州

13:30—14:20● 格底拉姆天空之城

15:00—15:30● 红海子

16:20—16:55🍜 康定快餐 + 补能

21:00—22:00◆ 崇州酒店 · 约560m

22:00作为驾驶上限；选择靠近高速、有停车位、可晚到的酒店，当晚完成车辆清理、补油和行李整理。

关键时间：14:20离开格底拉姆，15:30离开红海子，17:00前进入雅康高速。遇S434封路或恶劣天气时，按实时开放路线直达崇州。
