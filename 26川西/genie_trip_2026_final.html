27周日

D2｜新都桥 → 雅江 → 理塘 → 姊妹湖 → 巴塘海友

约400—450km纯驾驶约8—9h

10:00—12:30● 天路十八弯 / 卡子拉山 / 毛垭草原

沿G318向理塘推进，观景点只做快速停车拍照；若行程延误，直接压缩沿途停留，保留前往巴塘的时间。

12:30—13:00🍜 理塘午饭 ⛽ 理塘加满油

理塘快速午饭并加满油，13:00前离开；理塘至巴塘之间按无可靠加油点安排。

13:00—16:00○ 可选｜前往措普沟

午饭后视路况决定是否前往；只有在16:00前抵达游客中心，才安排现场购票和入园。

抵达后🎫 可选｜措普沟买票 / 入园

16:00前到达且景区仍可入园时再购票；若超过16:00，直接跳过措普沟，继续前往巴塘。

游览时间○ 可选｜措普沟精华

仅在时间、天气和景区末班景交允许时游览，不影响当晚抵达巴塘。

19:30—21:30◆ 海友酒店（甘孜巴塘店）· 约2,580m ⛽ 巴塘再次加满油

离开景区后沿铺装主路抵达巴塘。到店简单晚饭；完成油电补给，下载格聂南线离线地图，向下则通民宿确认次日道路和晚餐。

行程取舍：16:00前无法到达措普沟就直接跳过，不影响巴塘入住、加油和次日格聂南线反穿。
28周一

D3｜巴塘 → 夯达营地 → 则巴村 → 格聂之眼 → 下则通村

格聂南线反穿核心日；三个指定打卡点全部列为必到。

约210—250km纯驾驶约9—11h
07:00—08:00🍜 起床 + 压缩早餐/退房

08:00→ 准时反穿

地理顺序：巴塘 → 波密乡/格木村 → 扎瓦拉垭口 → 劳者龙巴 → 热梯河谷 → 夯达营地 → 则巴村 → 新冷古寺路口 → 格聂之眼 → 下则通村。提前下载离线地图，岔路结合民宿和现场指引确认。

09:00—13:00● 西段精华

扎瓦拉、格木村、劳者龙巴和热梯河谷每处控制10—20分钟；落石带、盲弯和涉水点保持连续通行。

13:00🍜 安全位置路餐

饮水和路餐在巴塘备齐，在视野开阔的停车位置用餐。

13:30—14:30● 必到 1｜夯达营地

在营地指定位置停车，拍摄格聂南坡和河谷；同时确认天气、车况和剩余日照时间。

14:40—15:40● 必到 2｜则巴村

村落和雪山机位停留约40—60分钟；车辆停在指定区域并保持村道通畅，15:40继续前往格聂之眼。

17:00—17:45● 必到 3｜格聂之眼

在正规停车位下车，沿现有步道接近并保护草甸。若17:30仍在途中，则调整为D4 09:30第一站。

顺路条件项○ 老冷古寺｜有余量则去

14:00前抵达新冷古寺、天气和身体状态良好、当地摩托或马匹可立即往返，并确认能在天黑前完成格聂之眼及入住时进入；时间不足则略过，D4按单向路线继续。

18:15—19:30◆ 格聂云庭富氧民宿 · 下则通村约3,800m

完成晚餐、供氧和停车，随后在下则通休息。

20:30—21:30★ 格聂银河 / 星空观察

步行前往民宿老板推荐的村内开阔安全点，面向西南观察；使用红光照明并适应黑暗约20分钟。根据云量和月光，在银河、星空与雪山月色之间选择拍摄主题。
